# Bine's KreativWerkstatt – korrigierte Projektversion

Diese Version nutzt die ursprüngliche Projektstruktur und Funktionen, aber das neue Schwarz-Rot-Design.

Wichtig: Die Unterseiten liegen jetzt direkt im Projektroot:
- index.html
- product.html
- kontakt.html
- gaestebuch.html
- impressum.html

Dadurch funktionieren die relativen Links lokal und auf GitHub Pages.

## Start in PyCharm
Rechtsklick auf `server.py` → Run 'server'.

Nicht `index.html` als Python-Datei ausführen.

## Navigation
Startseite → Shop → Produktdetail → Warenkorb/Checkout → Kontakt/Gästebuch/Impressum.

Die bestehenden JavaScript-Dateien und `data/store.json` wurden übernommen.


### Hintergrund
Der aktuelle `assets/background.png` ist der rote Drachen-Hintergrund. Bei einem bereits laufenden Browser bitte einmal hart neu laden (Strg+F5).
