Bine’s KreativWerkstatt – Hauptbild im Adminbereich

Neu:
- Beim Anlegen und Bearbeiten eines Produkts werden alle vorhandenen Produktbilder angezeigt.
- Jedes Bild hat die Auswahl „Hauptbild“.
- Das markierte Hauptbild wird im Shop direkt in der Produktübersicht angezeigt.
- Beim Hochladen mehrerer neuer Bilder kann ebenfalls ausgewählt werden, welches davon Hauptbild sein soll.
- Das Hauptbild bleibt auch beim Veröffentlichen über „Änderungen veröffentlichen“ erhalten.

Bei GitHub ersetzen:
- admin/admin.js
- js/shop.js

Danach im Browser Strg+F5 drücken.
